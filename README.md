# ELA Games

package is recorded in games-manifest.json and its PROVENANCE.md.

Published at https://theelahub.github.io/.

GitHub Pages serves this repository's main branch at `/`. The ELA Hub's Netlify
deployment is independent and is not triggered by updates to this repository.
